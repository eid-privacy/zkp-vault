# The Paper that Keeps Showing Up (Cronokirby, 2022)

## Summary
Blog post by Lúcás Meier on Ueli Maurer's "Unifying Zero-Knowledge Proofs of Knowledge", which generalises Schnorr's protocol to proofs of preimage for any group homomorphism. It shows how this single framework covers Schnorr, Pedersen-commitment openings, equality-of-discrete-log and the proofs used in attribute-based credentials. A concise intuition for the Sigma protocols underlying BBS and other anonymous credential schemes.
