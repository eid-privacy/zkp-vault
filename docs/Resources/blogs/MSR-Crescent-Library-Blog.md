# Crescent library brings privacy to digital identity systems (Microsoft Research, 2025)

## Summary
Microsoft Research blog post introducing the open-source Crescent library, which adds unlinkability and selective disclosure to existing JWT and mDL credentials by proving their RSA/ECDSA signatures in zero knowledge (Groth16 + Sigma proofs). It describes the pre-computation/online split that makes presentations fast on phones. Directly relevant to retrofitting privacy onto existing e-ID credential formats.
