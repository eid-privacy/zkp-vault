# Announcing the Expander Compiler Collection (ECC) (Polyhedra, 2024)

## Summary
Polyhedra Network's announcement of the Expander Compiler Collection, which compiles gnark circuits (R1CS) into a layered-circuit intermediate representation suitable for their GKR-based Expander prover. It explains why GKR needs layered circuits and how ECC bridges existing R1CS tooling to GKR proving. Relevant as an example of sumcheck/GKR provers, a family also used by Longfellow ZK.
