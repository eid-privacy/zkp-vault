# Which Computational Universe Do We Live In? (Quanta Magazine, 2022)

## Summary
Erica Klarreich's Quanta Magazine article on Impagliazzo's "five worlds" (Algorithmica, Heuristica, Pessiland, Minicrypt, Cryptomania) and recent progress linking the existence of one-way functions to Kolmogorov complexity. It explains which complexity-theoretic assumptions cryptography, including zero-knowledge proofs, depends on. Cited in the e-ID taxonomy as an accessible introduction to cryptographic hardness assumptions.
