# The Security Development Lifecycle

## Summary
Michael Howard and Steve Lipner's book (Microsoft Press, 2006) describing Microsoft's Security Development Lifecycle (SDL): security requirements, threat modeling, secure coding, testing and response processes for building demonstrably more secure software. Cited in the e-ID taxonomy as background for security engineering processes that a national e-ID and its wallet/verifier software should follow.
