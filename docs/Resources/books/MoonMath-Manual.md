# MoonMath Manual to zk-SNARKs

## Summary
Free beginner-oriented book by Least Authority that explains zk-SNARKs from the ground up with many worked "pen-and-paper" examples: modular arithmetic, finite fields, elliptic curves and pairings, circuits and R1CS/QAP, and the Groth16 protocol. LaTeX sources are on GitHub (LeastAuthority/moonmath-manual). Good preparation for reading the papers behind Groth16-based systems such as Crescent.
