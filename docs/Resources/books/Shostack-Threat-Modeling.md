# Threat Modeling: Designing for Security

## Summary
Adam Shostack's book (Wiley, 2014) on systematic threat modeling: the four-question framework, STRIDE, attack trees, data-flow diagrams, and how to integrate threat modeling into development. Used in the e-ID taxonomy work as a reference for structuring attacker models when comparing identity systems and the privacy guarantees that ZKPs can (and cannot) provide.
