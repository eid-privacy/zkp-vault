# Plonky2 and Starky (Polygon Zero)

## Summary
Rust implementation of Plonky2, Polygon Zero's recursive SNARK combining PLONK with FRI over the 64-bit Goldilocks field for very fast recursion. Rated 3.0/5 in the eid-privacy WP2 evaluation and noted as being on route to deprecation in favour of Plonky3.
