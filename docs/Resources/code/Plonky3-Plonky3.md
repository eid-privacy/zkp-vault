# Plonky3/Plonky3

## Summary
Modular Rust toolkit for polynomial IOPs, providing fields (BabyBear, Mersenne31, Goldilocks), FRI and circle-STARK commitments, and AIR-based STARK provers used by several zkVMs (e.g. SP1, OpenVM). Rated 3.8/5 in the eid-privacy WP2 evaluation: strong community, weak documentation and a high entry barrier.
