# Sphereon-Opensource/OID4VC (OpenID4VCI / OpenID4VP)

## Summary
TypeScript monorepo from Sphereon (formerly the OpenID4VCI repository, which now redirects here) with modules for issuers, holders and relying parties implementing OpenID for Verifiable Credentials, in particular OpenID4VCI. The companion repository [Sphereon-Opensource/SIOP-OID4VP](https://github.com/Sphereon-Opensource/SIOP-OID4VP) implements SIOPv2 and OpenID4VP.
