# Sphereon-Opensource/SSI-SDK

## Summary
Sphereon's (now legacy) TypeScript self-sovereign identity SDK built on Veramo, bundling plugins for DIDs, W3C VCs, SD-JWT, OpenID4VC, presentation exchange and wallet/agent functionality.
