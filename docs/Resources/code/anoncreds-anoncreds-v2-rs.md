# anoncreds/anoncreds-v2-rs

## Summary
Rust toolkit for AnonCreds v2 (Anonymous Credential Exchange 2.0) with a pluggable interface for ZKP-enabled signature suites, currently BBS and PS signatures, retaining AnonCreds v1 concepts (schemas, credential definitions, presentation requests) with unlinkable presentations, selective disclosure and blinded link secrets. Moved from hyperledger/anoncreds-v2-rs to the anoncreds organisation.
