# applied-crypto/heimdall

## Summary
Heimdall, a self-sovereign identity framework based on general-purpose ZKPs: credential presentations are implemented as Circom circuits (Groth16 zkeys) driven by the `heimdalljs` command-line tool. An early example of circuit-based privacy-preserving credentials, cited in the e-ID project notes.
