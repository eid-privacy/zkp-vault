# arkworks-rs/algebra

## Summary
Rust libraries for finite fields, elliptic curves (BLS12-381, BN254, secp256k1/r1, ...), pairings and polynomial arithmetic that underpin most of the Rust ZKP ecosystem (Groth16, Marlin, Crescent, docknetwork). Rated 5.0/5 in the eid-privacy WP2 library evaluation as the best-engineered and best-supported project surveyed.
