# arkworks-rs/crypto-primitives

## Summary
Rust interfaces and implementations of cryptographic primitives (hashes, Merkle trees, commitments, signatures, PRFs, sponges) together with their R1CS constraint gadgets, for use inside arkworks-based SNARK circuits. Rated 4.2/5 in the eid-privacy WP2 evaluation, with documentation noted as a weakness.
