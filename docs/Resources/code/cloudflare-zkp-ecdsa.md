# cloudflare/zkp-ecdsa

## Summary
Cloudflare's (archived) TypeScript implementation of ZKAttest: proving knowledge of an ECDSA-P256 signature under one of many public keys in a list, without revealing which. Reference code for proving ECDSA in zero knowledge for anonymous attestation and holder binding.
