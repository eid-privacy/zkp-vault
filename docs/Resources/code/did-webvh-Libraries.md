# did:webvh implementations (TypeScript, Python, Rust, Go)

## Summary
Implementations of the did:webvh (formerly did:tdw) DID method, used by swiyu for issuer/verifier identifiers: [didwebvh-ts](https://github.com/decentralized-identity/didwebvh-ts) (TypeScript, DIF), [didwebvh-py](https://github.com/decentralized-identity/didwebvh-py) (Python, DIF; formerly trustdidweb-py), [didwebvh-rs](https://github.com/decentralized-identity/didwebvh-rs) (Rust, DIF; the older `did-webvh` crate from Affinidi is now marked not recommended) and [trustdidweb-go](https://github.com/nuts-foundation/trustdidweb-go) (Go, Nuts Foundation). Listed in the eid-privacy WP2 DIDComm/DID survey.
