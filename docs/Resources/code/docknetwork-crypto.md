# docknetwork/crypto (incl. vb_accumulator)

## Summary
Dock Network's Rust cryptography workspace for anonymous credentials: BBS/BBS+/PS signatures, composite Sigma-protocol proofs, Bulletproofs++ range proofs, SAVER verifiable encryption, and the `vb_accumulator` crate (positive/universal VB accumulators with (non-)membership proofs) used for privacy-preserving revocation. Used by the eid-privacy proof-of-concept; rated 3.5/5 in the WP2 evaluation as one of the most comprehensive e-ID-focused crypto libraries.
