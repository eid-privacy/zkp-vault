# eid-privacy/SWIYU-Demo

## Summary
Proof-of-concept website from the eid-privacy project that issues and verifies credentials on top of the Swiss swiyu infrastructure, using the open-source swiyu issuer agents (management and OpenID4VCI) behind an Nginx proxy. Announced in [[eid-privacy-swiyu-demo]]; see [[swiyu]].
