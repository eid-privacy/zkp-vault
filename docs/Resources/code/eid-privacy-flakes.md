# eid-privacy/flakes

## Summary
Nix flakes from the eid-privacy project, with a Cachix binary cache, for pinned versions of Noir, Barretenberg and the Tom-256 `nargo-t256` from [[eid-privacy-noir-tom256]]. They can be added to a devbox project, so that circuits and benchmarks are reproducible across machines.
