# eid-privacy/noir

## Summary
Fork of the Noir language with Tom-256 / P-256 support, maintained on the `tom-256` branch (tags `t256-v0.26-*`) and used as `nargo-t256` by [[eid-privacy-spartan-backend]]. It lets Noir circuits for e-ID use Tom-256 points natively for ECDSA holder binding; see [[Noir]] and [[Holder-Binding]].
