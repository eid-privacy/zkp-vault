# eid-privacy/spartan-backend

## Summary
eid-privacy's Spartan backend for Noir: a series of increasingly complex Noir circuits (ACIR) proven with Spartan over T256, tracking the backend's evolution. Includes Crescent-style ECDSA holder binding (`circuits/c0100_holder_binding_crescent_style`), a swiyu SD-JWT presentation circuit (`circuits/c0200_swiyu_jwt`) and an e-ID circuit with non-revocation (`circuits/eid`). Demo code, not for production.
