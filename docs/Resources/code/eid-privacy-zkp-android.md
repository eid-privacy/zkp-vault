# eid-privacy/zkp-android

## Summary
Android app from the eid-privacy project that generates and verifies Noir proofs (UltraHONK, via Barretenberg) on the phone, including a full swiyu SD-JWT verification. Built with the mopro toolchain, which generates Kotlin bindings from Rust via UniFFI and JNA. Used to measure on-device proving times for the e-ID circuits; see [[ZKP-on-Mobile]].
