# eid-privacy/zkp-pocs

## Summary
Proof-of-concept repository of the eid-privacy project implementing e-ID proofs with docknetwork/crypto (BBS + Bulletproofs) and Noir (UltraHONK): holder binding (`noir/c03_holder_binding`), issuer signature, age verification, non-revocation against a signed revocation list (`noir/c06_non_revocation`), their combination, and full swiyu SD-JWT age proofs, with benchmarks.
