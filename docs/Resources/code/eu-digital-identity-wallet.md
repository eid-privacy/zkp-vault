# eu-digital-identity-wallet — EUDI Wallet reference implementation

## Summary
GitHub organisation of the European Commission's EUDI Wallet reference implementation: Android and iOS reference wallet apps and core libraries, PID/attestation issuers (e.g. eudi-srv-pid-issuer, eudi-srv-web-issuing-eudiw-py), verifier endpoints and web verifier, plus the ARF documentation. The baseline into which EU-level ZKP proposals (e.g. Longfellow for mdoc) are being integrated.
