# facebook/winterfell

## Summary
STARK prover and verifier for arbitrary computations expressed as AIR, written in Rust by Meta (Facebook), with multi-threaded proving and FRI-based commitments. A clean, well-documented reference for transparent, hash-based (plausibly post-quantum) proof systems.
