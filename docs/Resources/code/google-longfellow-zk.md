# longfellow-zk (Google)

## Summary
C++ implementation of Google's Longfellow ZK library for identity protocols (Ligero + sumcheck), including circuits for proving ECDSA-signed ISO mdoc credentials and SHA-256 in zero knowledge; the repository moved from google/longfellow-zk to the longfellow-zk organisation. Transparent and fast on phones; rated 3.5/5 in the eid-privacy WP2 evaluation (C++ only, APIs unclear).
