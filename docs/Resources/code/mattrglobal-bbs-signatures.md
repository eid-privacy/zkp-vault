# @mattrglobal/bbs-signatures (MATTR)

## Summary
MATTR's earlier JavaScript/WASM package implementing BBS+ signatures (Rust compiled to WASM), used by many early JSON-LD BBS+ credential prototypes. The original GitHub repository (github.com/mattrglobal/bbs-signatures) is no longer available; the package remains on npm and has been superseded by pairing_crypto.
