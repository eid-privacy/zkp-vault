# mattrglobal/pairing_crypto

## Summary
Rust library by MATTR implementing pairing-based cryptography, most notably the IETF/CFRG BBS signature scheme with proofs of knowledge for selective disclosure, with wrappers for several languages (WASM/JS, mobile). Rated 3.3/5 in the eid-privacy WP2 evaluation (weak documentation, many language bindings).
