# microsoft/bbs-node-reference

## Summary
TypeScript/Node reference implementation of the IETF/CFRG BBS signature scheme by Microsoft, meant to help understand and verify the specification (tracking draft-irtf-cfrg-bbs-signatures-12) rather than for production use. Useful for reading the BBS sign/verify/proof algorithms in compact form.
