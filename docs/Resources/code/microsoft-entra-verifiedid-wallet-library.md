# Microsoft Entra Verified ID wallet libraries (Android & iOS)

## Summary
Microsoft's native libraries for managing decentralised identities and Verified ID credentials in mobile wallets: [Android](https://github.com/microsoft/entra-verifiedid-wallet-library-android) and [iOS](https://github.com/microsoft/entra-verifiedid-wallet-library-ios). They implement the issuance and presentation flows (OpenID-based) used by Microsoft Entra Verified ID.
