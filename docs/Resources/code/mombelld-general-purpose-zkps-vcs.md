# mombelld/general-purpose-zkps-vcs

## Summary
Proof-of-concept verifiable-credentials infrastructure built on general-purpose zero-knowledge proofs (Circom-based circuits), companion to the master's thesis "General-Purpose Zero-Knowledge Proofs for Verifiable Credentials" contained in the repository. Includes a Docker-based end-to-end demo of issuance and verification; academic prototype, not for production.
