# openwallet-foundation/acapy (ACA-Py)

## Summary
ACA-Py: production-ready, server-side SSI agent for building issuers, holders, verifiers and DIDComm mediators, supporting AnonCreds and W3C VCs (JSON-LD Data Integrity, BBS+). Maintained by the OpenWallet Foundation; rated 5.0/5 in the eid-privacy WP2 DIDComm evaluation.
