# openwallet-foundation/didcomm-mediator-credo

## Summary
Easy-to-deploy Aries/DIDComm v1 mediator built on Credo (TypeScript), handling message routing and delivery for mobile agents that are not always online. Rated 5.0/5 in the eid-privacy WP2 DIDComm evaluation.
