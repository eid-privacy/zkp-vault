# personaelabs/spartan-ecdsa

## Summary
Fast in-browser zero-knowledge proofs of ECDSA (secp256k1) signature validity using Spartan over the secq256k1 curve with right-field arithmetic, from Personae Labs. Its curve-cycle trick inspired similar Spartan/T256-based approaches for ECDSA-P256 holder binding (e.g. Crescent).
