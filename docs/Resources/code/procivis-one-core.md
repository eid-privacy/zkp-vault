# procivis/one-core

## Summary
Procivis One Core: a Rust all-in-one engine to issue, hold and verify credentials on any device, supporting ISO 18013-5 mdocs, IETF SD-JWT VC, W3C VCs, OpenID4VC and eIDAS 2.0 profiles. Rated 3.5/5 in the eid-privacy WP2 evaluation.
