# scipr-lab/libiop

## Summary
C++ library for IOP-based zkSNARKs from SCIPR Lab, implementing Aurora, Ligero and Fractal over R1CS with FRI-based low-degree testing. A reference implementation for transparent, post-quantum-plausible SNARKs; rated 4.3/5 in the eid-privacy WP2 evaluation as a possible basis for IOP-based work.
