# sicpa-dlab/didcomm-python

## Summary
Python library from SICPA implementing basic DIDComm v2 messaging: packing/unpacking encrypted (authcrypt/anoncrypt) and signed messages, DID resolution hooks and forward/routing support. Part of a family with matching Rust and JVM implementations.
