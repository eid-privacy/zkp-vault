# sicpa-dlab/didcomm-rust

## Summary
Rust implementation of DIDComm v2 by SICPA, with bindings (WASM/JS, Swift, Kotlin via uniffi) for message encryption, signing and routing. Rated 3.7/5 in the eid-privacy WP2 evaluation of DIDComm libraries.
