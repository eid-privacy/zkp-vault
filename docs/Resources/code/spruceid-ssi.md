# spruceid/ssi

## Summary
SpruceID's core Rust library for decentralised identity: W3C VC data model, Data Integrity and JOSE/COSE proofs, SD-JWT, many DID methods and JSON-LD processing. Rated 5.0/5 in the eid-privacy WP2 VC-format evaluation (possibly the best in its category).
