# trustbloc/vcs

## Summary
TrustBloc Verifiable Credential Services: Go server-side issuer and verifier implementing OpenID4VCI/OpenID4VP, W3C VC data model, status lists and multiple signature suites; the backend counterpart of trustbloc/wallet-sdk.
