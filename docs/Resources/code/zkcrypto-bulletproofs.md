# zkcrypto/bulletproofs

## Summary
Pure-Rust implementation of Bulletproofs over the Ristretto group (a fork of dalek-cryptography/bulletproofs), providing fast range proofs and an R1CS constraint-system API. Range proofs are needed e.g. for age predicates on credentials; rated 3.3/5 in the eid-privacy WP2 evaluation.
