# ZK Learning Resources by 0xPARC

## Summary
Collection of learning materials that grew out of 0xPARC's first Applied ZK Learning Group, maintained by community volunteers. It contains hands-on tracks for writing circuits in Circom and Halo2, explainers (e.g. R1CS), and recorded lectures. A practical entry point for developers who want to write ZK circuits such as those used in e-ID proof-of-concepts.
