# ZKDL Camp — Lectures on Zero-Knowledge Proving Systems (Distributed Lab)

## Summary
Lecture series run at Distributed Lab that builds modern zk-SNARKs such as Groth16, PlonK and GKR "from scratch", including all of the underlying mathematics (finite fields, elliptic curves, pairings, polynomial commitments). Each lecture comes with notes and slides, and the material has been compiled into an open book. A good self-study path for engineers who need a low-level understanding of the proof systems used in ZKP-based e-ID prototypes.
