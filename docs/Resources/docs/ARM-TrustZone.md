# Arm TrustZone for Cortex-A

## Summary
Arm's overview of TrustZone, the hardware security extension that partitions a Cortex-A system into a Normal World and a Secure World, providing the isolation on which mobile TEEs (Trusty, QSEE, Kinibi) are built. Arm's developer documentation (Learn the architecture: TrustZone for AArch64) gives the technical details.
