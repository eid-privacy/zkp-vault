# Android Trusty TEE

## Summary
AOSP documentation for Trusty, Google's open-source trusted execution environment OS that runs alongside Android on the same processor (typically isolated via ARM TrustZone) and hosts trusted apps such as KeyMint and Gatekeeper. Relevant for understanding where Android wallet keys live and what a TEE does and does not protect against.
