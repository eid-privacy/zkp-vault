# Apple CryptoKit — SecureEnclave

## Summary
Apple developer documentation for the CryptoKit SecureEnclave API, which lets iOS/macOS apps create and use P-256 signing and key-agreement keys whose private parts never leave the Secure Enclave. This is the API wallet apps use for hardware-backed holder binding on iPhones, constraining which signature schemes a ZKP-based holder-binding proof must support.
