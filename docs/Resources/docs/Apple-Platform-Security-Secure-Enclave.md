# Apple Platform Security — The Secure Enclave

## Summary
Chapter of Apple's Platform Security Guide describing the Secure Enclave hardware: isolated processor, memory protection engine, boot chain, true random number generator and the Secure Enclave AES/PKA engines. Background for assessing the device-binding guarantees that e-ID wallets on iOS obtain from hardware keys.
