# EUDI Wallet Architecture and Reference Framework (ARF)

## Summary
Repository of the European Digital Identity Wallet Architecture and Reference Framework, the technical blueprint for EUDI wallets (PID, attestations, mdoc and SD-JWT VC, OpenID4VCI/VP, trust model). Its discussion topics are especially relevant for ZKPs: topic G (Zero-Knowledge Proofs), topic E (Pseudonyms, including user authentication) and topic C (Wallet Unit Attestation), alongside A (privacy risks and mitigations) and B (batch issuance for unlinkability). The latest release is v3.0.0 (July 2026); topics E and G are in the 2026 refinement round.
