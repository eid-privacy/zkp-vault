# WP2 Libraries and Protocols — evaluated libraries tables (eid-privacy)

## Summary
Internal catalogue from the eid-privacy project (WP2), kept in the private repository `eid-privacy/WP2-Libraries`. It evaluated cryptographic libraries and protocols for e-ID/SSI and gave each entry a 1–5 quality score per criterion (software structure, tests/CI, licence, amenity to change, documentation, ...) for ZK libraries (Arkworks, Crescent, Docknetwork, Longfellow, MATTR pairing_crypto, Plonky2/3, Spartan, Bulletproofs), ZK circuit frameworks (Circom, libiop, Noir, Halo2), DIDComm libraries (ACA-Py, Credo mediator, didcomm-rust, Veramo) and VC-format libraries (did-jwt, Procivis One Core, SpruceID ssi). The criteria and all scores are published in [[Library-Evaluation]].
