# WP2 Libraries and Protocols — evaluated libraries tables (eid-privacy)

## Summary
Living catalogue from the eid-privacy project (WP2) that evaluates cryptographic libraries and protocols for e-ID/SSI. Its README contains generated tables with a 1–5 quality score per entry (software structure, tests/CI, licence, amenity to change, documentation, ...) for ZK libraries (Arkworks, Crescent, Docknetwork, Longfellow, MATTR pairing_crypto, Plonky2/3, Spartan, Bulletproofs), ZK circuit frameworks (Circom, libiop, Noir, Halo2), DIDComm libraries (ACA-Py, Credo mediator, didcomm-rust, Veramo) and VC-format libraries (did-jwt, Procivis One Core, SpruceID ssi). It also links the D2.x deliverables.
