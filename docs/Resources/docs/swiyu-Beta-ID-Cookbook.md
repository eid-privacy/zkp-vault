# swiyu Cookbook — How to use Beta-ID for my business

## Summary
swiyu cookbook explaining how businesses can use the Beta-ID — the test credential of the swiyu public beta that mirrors the future Swiss E-ID — including its credential details (SD-JWT VC attributes) and how to request it in a verification flow. Useful for building and testing ZKP proofs-of-concept against realistic Swiss credentials.
