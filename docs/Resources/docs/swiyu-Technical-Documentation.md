# swiyu Technical Documentation and GitHub Organisation

## Summary
Official technical documentation of swiyu, the Swiss federal trust infrastructure and wallet for the E-ID: introduction, technology stack (SD-JWT VC, OpenID4VCI/VP, did:webvh, Token Status List), specifications, cookbooks, threat model, roadmap and change dossiers. The open-source components (wallet apps, generic issuer/verifier, registries) are published in the [swiyu-admin-ch GitHub organisation](https://github.com/swiyu-admin-ch).
