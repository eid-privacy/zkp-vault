# swiyu Trust Protocol 2.0 Specification

## Summary
Specification of the trust protocol of the Swiss swiyu trust infrastructure: how the base registry (DIDs) and trust registry establish and publish trust statements about issuers and verifiers, so that wallets can check who is asking for which data. Version 2.0 replaces the earlier v0.1 protocol (archived on the same site).
