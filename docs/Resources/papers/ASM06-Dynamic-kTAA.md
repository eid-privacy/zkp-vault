# Constant-Size Dynamic k-TAA (Au, Susilo, Mu 2006)

## Summary
Proposes a dynamic k-times anonymous authentication (k-TAA) scheme with constant-size proofs, in which users authenticate anonymously up to k times per verifier, and over-use is detectable and traceable. The construction introduced the signature scheme now known as BBS+ (a variant of the Boneh–Boyen–Shacham group-signature building block that signs message blocks and supports efficient proofs of knowledge), the basis of today's BBS anonymous-credential standardization relevant to the EUDI wallet. (SCN 2006.)
