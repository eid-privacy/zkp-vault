# Cryptographic Accumulators: New Definitions, Enhanced Security, and Delegatable Proofs (Barthoulot, Blazy, Canard 2024)

## Summary
Gives a unified, modern definition of cryptographic accumulators covering dynamic, universal and zero-knowledge variants, introduces a new security notion (unforgeability of private evaluation), and discusses delegatable (non-)membership proofs. Good reference for the security properties an accumulator-based revocation scheme for e-ID credentials must satisfy.
