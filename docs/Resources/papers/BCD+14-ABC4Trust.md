# D2.2 Architecture for Attribute-based Credential Technologies — Final Version (ABC4Trust) (Bichsel et al. 2014)

## Summary
Final architecture deliverable of the EU ABC4Trust project, which unified Privacy-ABC systems (IBM Identity Mixer / CL signatures and Microsoft U-Prove) behind a common, mechanism-independent architecture and data formats for issuers, users, verifiers, revocation and inspection authorities. It describes the full feature set (selective disclosure, pseudonyms, inspection/conditional disclosure, revocation, key binding) and how to compose it from signatures and Schnorr-type proofs. [[BL26-SoK-AnonCreds]] presents itself as an updated, wallet-centric version of this overview.
