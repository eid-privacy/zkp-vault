# Issuer-Hiding Attribute-Based Credentials (Bobolz, Eidens, Krenn, Ramacher, Samelin 2021)

## Summary
Defines and constructs issuer-hiding attribute-based credentials, where a presentation only shows that the credential was issued by one of a verifier-chosen set of accepted issuers, without revealing which one (CANS 2021). This is useful for e.g. proving a degree from "some accredited university". Listed in [[BL26-SoK-AnonCreds]] as one of the advanced features compatible with Schnorr-style credential systems.
