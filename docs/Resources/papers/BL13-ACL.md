# Anonymous Credentials Light (Baldimtsi, Lysyanskaya 2013)

## Summary
A lightweight, pairing-free, single-use anonymous credential scheme built from a blind signature with attributes, proven secure in the random oracle model (ACM CCS 2013). Like U-Prove it is single-show, so unlinkability across presentations needs batch issuance. Later work showed attacks on concurrent issuance sessions. Cited in [[BL26-SoK-AnonCreds]] as a pairing-free alternative.
