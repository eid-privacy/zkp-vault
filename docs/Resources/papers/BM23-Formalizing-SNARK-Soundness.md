# Formalizing Soundness Proofs of SNARKs (Bailey, Miller 2023)

## Summary
Mechanizes soundness proofs of SNARK constructions in the Lean theorem prover, so that a proof system's security argument can be machine-checked rather than only reviewed by hand. Cited in [[BL26-SoK-AnonCreds]] as ongoing work towards formal verification of proof systems, which it considers essential given the complexity of general-purpose ZKPs.
