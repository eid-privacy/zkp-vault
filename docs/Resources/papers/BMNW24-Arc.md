# Arc: Accumulation for Reed–Solomon Codes (Bünz, Mishra, Nguyen, Wang 2024)

## Summary
Gives the first accumulation scheme for proximity claims to Reed–Solomon codes, which supports an unbounded number of accumulation steps using only hash functions (unlike earlier hash-based schemes limited to a bounded depth). This enables proof-carrying data and IVC built from hash-based, plausibly post-quantum primitives with FRI/STARK-style commitments, a key ingredient for recursive transparent proof systems.
