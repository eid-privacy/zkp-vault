# Algebraic MACs and Keyed-Verification Anonymous Credentials (Chase, Meiklejohn, Zaverucha 2014)

## Summary
Introduces keyed-verification anonymous credentials (KVAC), where issuer and verifier share a secret key, so credentials can be built from algebraic MACs in prime-order groups without pairings. Presentations use efficient Sigma-protocol proofs. The CMZ construction is the basis of Signal's private groups and of later KVAC work ([[BBDT16-KVAC]], [[Orr25-Revisiting-KVAC]]), and indirectly of server-aided credentials such as BBS# ([[CHLT25-Server-Aided-AC]]).
