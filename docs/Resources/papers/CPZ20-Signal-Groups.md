# The Signal Private Group System and Anonymous Credentials Supporting Efficient Verifiable Encryption (Chase, Perrin, Zaverucha 2020)

## Summary
Describes Signal's private group system, in which the server stores encrypted group membership and members authenticate with keyed-verification anonymous credentials. The credentials support efficient verifiable encryption of attributes. One of the largest real-world deployments of anonymous credentials, cited in [[BL26-SoK-AnonCreds]] as evidence that pairing-free KVACs are deployable.
