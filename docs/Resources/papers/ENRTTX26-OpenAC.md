# OpenAC: Open Design for Transparent and Lightweight Anonymous Credentials (Eagen, Ngo, Rushi, Tong, Tsai, Xia 2026)

## Summary
Proposes OpenAC, an anonymous credential design that avoids the drawbacks of existing systems — no trusted setup, no substantial changes to an issuer's existing issuance flow, and no dependence on special hardware — while still achieving unlinkability across heterogeneous digital-identity ecosystems and current verifiable credential standards. Built with zero-knowledge proofs and engineered for efficient client-side proving on mobile devices; the authors report best-in-class proving times in a proof-of-concept implementation and map OpenAC's design against the European Digital Identity Architecture and Reference Framework (EUDI ARF) requirements in an appendix.
