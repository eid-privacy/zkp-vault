# Security Analysis of the Swiss e-ID & Trust Infrastructure (Egger 2025)

## Summary
EPFL master's thesis (HexHive, supported by FOITT and the Cyber Defence Campus) presenting a systematic security analysis of the Swiss e-ID trust infrastructure (swiyu), a nationwide SSI deployment with a centralised registry. It builds a threat model per ecosystem component and attack trees for the key security goals, uses them to guide source-code review, and reports more than 90 vulnerabilities, more than half of which were already fixed or accepted in collaboration with the development team. Useful context on the concrete system into which ZKP-based credential presentations would have to be integrated.
