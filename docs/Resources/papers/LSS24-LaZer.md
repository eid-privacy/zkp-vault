# The LaZer Library: Lattice-Based Zero Knowledge and Succinct Proofs for Quantum-Safe Privacy (Lyubashevsky, Seiler, Steuer 2024)

## Summary
A library that makes lattice-based zero-knowledge and succinct proofs, including LaBRADOR, usable by non-experts by handling the many instance-dependent parameters automatically (ACM CCS 2024). A practical entry point for post-quantum privacy-preserving credentials.
