# An Architecture for Distributed Digital Identities in the Physical World (Mayrhofer, Roland, Höller, Hofer, Lins 2025)

## Summary
Proposes a decentralized digital-identity architecture for physical-world interactions such as door access, public transport and border crossing, centred on a Personal Identity Agent that represents an individual's identity attributes, with central components optional and only aiding discovery and latency. A first protocol is formally verified against strong (global) adversaries, and a proof of concept shows practicality for applications tolerating a few seconds of latency. Offers a privacy-focused alternative architecture to wallet-centric e-ID designs.
