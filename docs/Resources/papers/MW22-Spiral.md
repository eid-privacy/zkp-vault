# Spiral: Fast, High-Rate Single-Server PIR via FHE Composition (Menon, Wu 2022)

## Summary
Presents Spiral, a family of single-server private information retrieval (PIR) protocols that compose Regev and GSW lattice-based homomorphic encryption to achieve high rate and fast server throughput. Single-server PIR lets a client fetch, e.g., a revocation-list entry or a trust-registry record without revealing which one it queried, complementing ZKPs for metadata privacy in e-ID systems. (IEEE S&P 2022.)
