# General-Purpose Zero-Knowledge Proofs for Verifiable Credentials (Mombelli 2025)

## Summary
ETH Zurich master's thesis (Applied Cryptography Group, with the Cyber Defence Campus) studying whether general-purpose zkSNARKs can provide flexible, privacy-preserving verification logic for the Swiss e-ID. It compares and benchmarks state-of-the-art ZKP frameworks, designs credential-verification logic as arithmetic circuits (Circom), and integrates a proof-of-concept anonymous-credential framework into the Swiss e-ID infrastructure, including proofs over values aggregated from multiple linked credentials. It also reports performance and tooling limitations of current frameworks. Code: https://github.com/mombelld/general-purpose-zkps-vcs.
