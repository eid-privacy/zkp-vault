# SoK: Managing risks of linkage attacks on data privacy (Powar, Beresford 2023)

## Summary
Systematizes linkage attacks, where auxiliary information is combined with released data to re-identify individuals, and the defenses against them (de-identification, k-anonymity, differential privacy, access control). Provides a framework for assessing linkage risk in data-sharing settings. Directly relevant to e-ID: unlinkability across presentations is the core property ZKP credentials aim to provide, and this SoK frames what correlation an adversary can still exploit.
