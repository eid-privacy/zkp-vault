# Short Randomizable Signatures (Pointcheval, Sanders 2016)

## Summary
Introduces Pointcheval–Sanders (PS) signatures (CT-RSA 2016), a pairing-based multi-message signature that can be re-randomized, so a holder can present a fresh-looking signature each time and prove knowledge of the signed messages efficiently. Signatures are constant-size (two group elements). PS signatures are, together with BBS, a main building block of anonymous credential systems (e.g. Coconut) considered for e-ID.
