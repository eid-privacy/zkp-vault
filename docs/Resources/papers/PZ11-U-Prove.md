# U-Prove Cryptographic Specification V1.1 (Paquin, Zaverucha 2011)

## Summary
Microsoft's specification of U-Prove, a pairing-free anonymous credential system based on Brands' blind signatures with attributes. U-Prove tokens support selective disclosure, but they can only be shown once without becoming linkable, so multi-show unlinkability needs batch issuance. [[BL26-SoK-AnonCreds]] cites it as the most prominent pairing-free, one-time-use credential approach.
