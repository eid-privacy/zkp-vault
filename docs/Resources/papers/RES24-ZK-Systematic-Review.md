# Systematic review: Comparing zk-SNARK, zk-STARK, and bulletproof protocols for privacy-preserving authentication (Oude Roelink, El-Hajj, Sarmah 2024)

## Summary
Systematic literature review (Security and Privacy, 2024) of works using zk-SNARKs, zk-STARKs and Bulletproofs for privacy-preserving authentication across financial, medical and other domains. Finds performance figures varying by orders of magnitude across implementations and inconsistent security-analysis methodologies, making comparisons difficult. Useful as an entry point when choosing a proof system for e-ID predicate proofs.
