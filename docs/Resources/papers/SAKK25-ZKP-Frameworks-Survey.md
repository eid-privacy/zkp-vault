# Zero-Knowledge Proof Frameworks: A Systematic Survey (Sheybani, Ahmed, Kinsy, Koushanfar 2025)

## Summary
Surveys and benchmarks 25 general-purpose open-source ZKP frameworks, assessing usability and performance on SHA-256 and matrix-multiplication workloads, and ships Docker containers with working development environments for each. It concludes with recommendations for choosing a ZKP setting per application scenario. Useful as a practical starting point for selecting a framework, e.g. for e-ID credential circuits.
