# Efficient Signature Generation by Smart Cards (Schnorr 1991)

## Summary
Presents the Schnorr identification protocol and, via the Fiat–Shamir heuristic, the Schnorr signature scheme, designed to be cheap enough for smart cards (most work can be precomputed). The Schnorr protocol is the canonical Sigma protocol (proof of knowledge of a discrete logarithm) and the template for the proofs of knowledge used in anonymous credentials. (Journal of Cryptology 4(3), 1991; conference version CRYPTO '89.)
