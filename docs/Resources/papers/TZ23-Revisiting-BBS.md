# Revisiting BBS Signatures (Tessaro, Zhu 2023)

## Summary
Revisits BBS signatures (Eurocrypt 2023): proves the security of a shorter variant whose signature is a single group element plus one scalar, and gives a tight analysis of the corresponding proof of knowledge used for selective disclosure. This is the version standardized in the IRTF CFRG BBS draft. Central to e-ID anonymous credentials, since BBS is the leading pairing-based candidate for unlinkable selective disclosure.
