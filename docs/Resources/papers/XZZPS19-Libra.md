# Libra: Succinct Zero-Knowledge Proofs with Optimal Prover Computation (Xie, Zhang, Zhang, Papamanthou, Song 2019)

## Summary
Presents Libra, the first ZKP system with both an optimal linear-time prover and succinct proof size and verification time for log-space uniform layered circuits. It gives a linear-time GKR prover algorithm for arbitrary circuits and a cheap zero-knowledge transformation of GKR via small masking polynomials, combined with a zero-knowledge polynomial commitment (one-time trusted setup). Libra demonstrates that GKR-based provers can be among the fastest in practice. (CRYPTO 2019.)
