# DIDComm Messaging v2.x (DIF)

## Summary
Decentralized Identity Foundation specification for secure, transport-agnostic, DID-based messaging: JWM envelopes with authenticated (authcrypt) or anonymous (anoncrypt) encryption, signing, mediators and routing. An alternative to OpenID4VC for issuer-wallet-verifier communication, evaluated in the e-ID project's WP2 protocol survey.
