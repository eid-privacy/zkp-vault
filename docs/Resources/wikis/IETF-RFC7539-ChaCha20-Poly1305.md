# RFC 7539: ChaCha20 and Poly1305 for IETF Protocols

## Summary
IETF RFC (2015, since obsoleted by RFC 8439) specifying the ChaCha20 stream cipher, the Poly1305 authenticator and their AEAD combination. Referenced in the e-ID project notes as one of the standard symmetric primitives available to wallet and protocol implementations.
