# BBS per Verifier Linkability — IRTF CFRG draft

## Summary
Extension of the CFRG BBS draft adding pseudonyms: from a holder secret embedded in a blindly-signed BBS credential, the holder derives a verifier-specific pseudonym that is stable for one verifier (context) but unlinkable across verifiers, and proves its correctness in the BBS presentation. This is the standards-track version of the certified, context-bound pseudonyms described in [[BL26-SoK-AnonCreds]].
