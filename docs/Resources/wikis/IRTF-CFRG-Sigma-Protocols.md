# Sigma Protocols — IRTF CFRG draft

## Summary
CFRG draft specifying a generic framework for Sigma protocols (proofs of knowledge of preimages of linear maps over prime-order groups) and their non-interactive versions via Fiat-Shamir. This gives a standard basis for Schnorr-style proofs as used by BBS presentations, pseudonyms and other anonymous-credential extensions. [[BL26-SoK-AnonCreds]] sees it as a promising route to modular, standardized extensions of DL-based multi-message signatures.
