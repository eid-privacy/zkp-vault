# ISO/IEC 18013-5:2021 — Mobile driving licence (mDL) application

## Summary
International standard defining the mobile driving licence (mDL) and the underlying ISO mdoc credential format: CBOR-encoded data elements with salted-hash selective disclosure, an issuer-signed Mobile Security Object (ECDSA), device binding via a device key, and proximity presentation over BLE/NFC. mdoc is one of the two mandated formats in the EUDI wallet, and Longfellow ZK and Crescent both target ZK proofs over mdoc signatures.
