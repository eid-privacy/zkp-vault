# FIPS 197: Advanced Encryption Standard (AES)

## Summary
NIST standard specifying the AES block cipher (originally 2001, updated 2023). Background reference for symmetric primitives used in credential transport and storage, and for MPC-in-the-head/ZK constructions that prove AES evaluations.
