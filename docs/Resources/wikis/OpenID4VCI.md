# OpenID for Verifiable Credential Issuance 1.0

## Summary
OpenID Foundation final specification (September 2025) defining an OAuth 2.0-protected API for issuing verifiable credentials (SD-JWT VC, mdoc, W3C VC) to wallets, including credential offers, pre-authorized code flow and key proofs for holder binding. Used for issuance in both swiyu and the EUDI wallet.
