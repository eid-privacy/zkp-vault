# OpenID for Verifiable Presentations 1.0

## Summary
OpenID Foundation final specification (July 2025) for requesting and presenting verifiable credentials from a wallet to a verifier, with the DCQL query language and support for multiple credential formats. The presentation protocol into which ZKP-based presentations (e.g. Longfellow or Crescent proofs) must be integrated in swiyu and EUDI deployments.
