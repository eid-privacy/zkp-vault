# Overlays Capture Architecture (OCA)

## Summary
Specification (Human Colossus Foundation) for describing data schemas as a capture base plus task-specific overlays (labels, formats, encodings, sensitive-attribute flags, presentation). swiyu uses OCA to describe how credential attributes are rendered in the wallet.
