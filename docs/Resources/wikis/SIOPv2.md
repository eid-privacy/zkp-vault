# Self-Issued OpenID Provider v2 (SIOPv2)

## Summary
OpenID Foundation draft extending OpenID Connect so that an end user can act as their own OpenID Provider, issuing self-signed ID tokens (optionally bound to DIDs) from a wallet. Often combined with OpenID4VP for wallet-based authentication.
