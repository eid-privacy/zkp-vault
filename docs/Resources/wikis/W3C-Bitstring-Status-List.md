# Bitstring Status List v1.0 (W3C Recommendation)

## Summary
W3C Recommendation (May 2025) for publishing revocation/suspension status of W3C Verifiable Credentials as a compressed bitstring inside a status-list credential. Herd privacy comes from the size of the list, but the verifier still learns the holder's index. The W3C counterpart of the IETF Token Status List and a baseline for privacy-preserving (ZK) non-revocation schemes.
