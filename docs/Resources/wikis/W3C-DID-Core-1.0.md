# Decentralized Identifiers (DIDs) v1.0 (W3C Recommendation)

## Summary
W3C Recommendation (July 2022) defining DIDs: URIs that resolve to DID documents containing verification methods and service endpoints, with the resolution mechanism delegated to individual DID methods. swiyu uses DIDs (did:tdw/did:webvh) to identify issuers and verifiers in its trust infrastructure.
