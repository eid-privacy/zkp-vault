# JSON-LD 1.1 (W3C Recommendation)

## Summary
W3C Recommendation (July 2020) for JSON-based Linked Data serialisation using @context to map terms to IRIs. W3C Verifiable Credentials rely on it, and Data Integrity cryptosuites (including BBS) canonicalise JSON-LD into RDF statements before signing — the messages over which selective disclosure operates.
