# Data Integrity BBS Cryptosuites v1.0 (W3C)

## Summary
W3C Candidate Recommendation specifying how to use BBS signatures as a Data Integrity cryptosuite for W3C Verifiable Credentials, yielding selective disclosure and unlinkable derived proofs, including features such as anonymous holder binding and pseudonyms. It connects the CFRG BBS draft to the JSON-LD VC data model.
