# Verifiable Credentials Data Model v1.1 (W3C Recommendation)

## Summary
W3C Recommendation (March 2022) defining the original JSON-LD data model for verifiable credentials and presentations (issuer, credentialSubject, proof). Superseded by v2.0 but still widely deployed in earlier SSI ecosystems.
