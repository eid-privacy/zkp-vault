# Verifiable Credentials Data Model v2.0 (W3C Recommendation)

## Summary
W3C Recommendation (May 2025) revising the VC data model: a JSON-LD-based structure for credentials and presentations secured by Data Integrity proofs or JOSE/COSE, with status, schema and refresh extensions. The data model on which BBS Data Integrity cryptosuites and Bitstring Status List build.
