# Concatenated error correction code (Wikipedia)

## Summary
Wikipedia article on concatenated codes (Forney, 1966), which combine an outer code (typically Reed-Solomon) with an inner code to obtain long codes with good distance and efficient decoding. Concatenation and related code constructions appear in linear-code-based polynomial commitments and IOPs (e.g. Ligero/Brakedown-style systems), where encoding speed and distance directly affect prover time and soundness.
