# did:web Method Specification (W3C CCG)

## Summary
W3C Credentials Community Group specification for the did:web method, which maps a DID to a DID document hosted at a well-known HTTPS location on a domain. Simple to deploy but relies entirely on DNS/TLS and keeps no history of key changes — limitations that motivated did:webvh.
