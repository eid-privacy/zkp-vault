# The did:webvh DID Method — did:web + Verifiable History (v1.0)

## Summary
DIF specification (formerly "Trust DID Web", did:tdw) extending did:web with a cryptographically chained, verifiable log of DID document versions, self-certifying identifiers, pre-rotation keys and witnesses. swiyu uses this method for issuer and verifier identifiers in its base registry.
